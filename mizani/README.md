# ميزاني — تسجيل الدخل والمصروفات الشخصية

تطبيق ويب تقدّمي (PWA) عربي بالكامل (RTL) لتسجيل الدخل والمصروفات ومراجعتها شهريًا أو لأي فترة، مع صور الإيصالات والتقارير والنسخ الاحتياطي. **يعمل محليًا بالكامل**: لا حساب، لا خادم، لا خدمات تحليلات.

## التشغيل محليًا

المتطلبات: Node.js 20 أو أحدث.

```bash
cd mizani
npm install
npm run dev        # خادم التطوير: http://localhost:5173
```

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build` | فحص TypeScript ثم بناء نسخة الإنتاج في `dist/` |
| `npm run preview` | معاينة نسخة الإنتاج محليًا (http://localhost:4173) |
| `npm test` | اختبارات الوحدة (الحساب، التواريخ، قاعدة البيانات، النسخ الاحتياطي، CSV) |
| `npm run e2e` | اختبار متصفح شامل (يتطلب تشغيل `npm run preview` أولًا) |
| `npm run icons` | إعادة توليد أيقونات PNG من `public/icon.svg` |

## نسخة الإنتاج والنشر

`npm run build` يُنتج مجلد `dist/` ثابتًا بمسارات نسبية، فيمكن رفعه على أي استضافة ملفات ثابتة (GitHub Pages، Netlify، خادم عادي). يجب أن تكون الاستضافة عبر **HTTPS** (أو `localhost`) حتى يعمل Service Worker والتثبيت والعمل دون اتصال. التنقل يعتمد على `#` في الروابط فلا يحتاج إعدادات خاصة في الخادم.

### النشر على GitHub Pages (تلقائي)

ملف `.github/workflows/deploy-pages.yml` يختبر التطبيق ويبنيه وينشره عند كل دفع إلى الفرع `main`:

- `https://<اسم-المستخدم>.github.io/student-arabic-tracker/` ← نظام متابعة الطلاب (كما هو)
- `https://<اسم-المستخدم>.github.io/student-arabic-tracker/mizani/` ← تطبيق ميزاني

للتفعيل مرة واحدة: **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.

## تثبيت التطبيق (PWA)

- **أندرويد / Chrome / Edge**: افتح التطبيق ← قائمة المتصفح ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون / Safari**: زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **الحاسوب**: أيقونة التثبيت في شريط العنوان.

بعد أول تحميل تعمل الواجهة دون إنترنت.

## التخزين المحلي وحدوده

- الحركات والتصنيفات والإعدادات وصور الإيصالات محفوظة في **IndexedDB** داخل المتصفح (عبر Dexie)، ولا يُستخدم localStorage إلا لتذكّر السمة (فاتح/داكن) تجنبًا للوميض.
- البيانات **لا تتزامن بين الأجهزة أو المتصفحات**. حذف بيانات الموقع من المتصفح، أو استخدام التصفح الخاص، أو فقد الجهاز يعني فقد السجلات إن لم توجد نسخة احتياطية.
- قد يحذف المتصفح بيانات المواقع عند امتلاء التخزين؛ من الإعدادات اطلب «التخزين الدائم» لتقليل هذا الاحتمال.
- تُضغط الصور الكبيرة (أكبر بُعد 2200 بكسل) مع الحفاظ على وضوحها. الحد: 3 صور لكل حركة، و5 ميغابايت للصورة الأصلية.

## النسخ الاحتياطي والاستعادة

من **الإعدادات ← النسخ الاحتياطي والاستعادة**:

- **تنزيل نسخة احتياطية** ينشئ ملف ZIP يحتوي `mizani-backup.json` (رقم إصدار البنية، الحركات، التصنيفات، الإعدادات، بيانات المرفقات) ومجلد `receipts/` بملفات الصور.
- **الاستعادة** تتحقق من سلامة الملف بالكامل أولًا، وتعرض عدد الحركات والمرفقات والفترة، ثم تختار:
  - **دمج**: يضيف ما ليس موجودًا فقط حسب المعرّف، دون تكرار ودون تعديل سجلاتك.
  - **استبدال**: يحذف بياناتك الحالية ويضع النسخة مكانها (بعد تأكيد صريح).
- إن فشلت الاستعادة لأي سبب لا تتغير بياناتك (العملية ذرّية).

احتفظ بنسخة احتياطية دوريًا في مكان آمن (بريدك أو التخزين السحابي الخاص بك).

## قواعد الحساب

- الفترة **شاملة** ليوم البداية ويوم النهاية، والشهر الميلادي الحالي هو الافتراضي.
- الصافي = إجمالي الدخل − إجمالي المصروفات، وقد يكون سالبًا. **ليس رصيدًا بنكيًا ولا ربحًا.**
- المبالغ تُخزن أعدادًا صحيحة بوحدة 1/100 (`amountMinor`، مثل الهللات) لتجنب أخطاء الكسور العشرية؛ الإدخال يقبل الأرقام العربية `١٢٣٤٫٥٠` والإنجليزية `1234.50`.
- التاريخ نص محلي `YYYY-MM-DD` لا يمر بتحويلات المناطق الزمنية.
- تغيير العملة يغيّر الرمز المعروض فقط ولا يحوّل المبالغ بأسعار الصرف.

## البنية التقنية

React 18 + TypeScript + Vite · Tailwind CSS · Lucide · Dexie/IndexedDB · React Hook Form + Zod · Recharts · JSZip · vite-plugin-pwa (Workbox).
الخطوط: Alexandria للعناوين وIBM Plex Sans Arabic للنصوص (رخصة SIL OFL)، مضمّنة محليًا عبر Fontsource لتعمل دون اتصال.

```
src/
  lib/        المال والتواريخ والعملات والصور والتنزيل (منطق صافٍ)
  db/         الأنواع، Dexie، التصنيفات الافتراضية، عمليات التخزين (repo)
  domain/     التقارير والتصفية، CSV، النسخ الاحتياطي
  state/      السياقات (الإعدادات، الفترة، التنبيهات) واستعلامات حيّة
  components/ مكونات الواجهة (نوافذ، رسوم، صفوف، مدير التصنيفات…)
  pages/      الرئيسية، الحركات، النموذج، التقارير، الطباعة، الإعدادات
tests/        اختبارات Vitest مع fake-indexeddb
e2e/          اختبار متصفح Playwright للتدفقات الأساسية
```

البنية تفصل العرض عن المنطق والتخزين، ونموذج البيانات مرقّم الإصدار (`DATA_SCHEMA_VERSION`) لتسهيل إضافة الحسابات المتعددة أو الميزانيات أو المزامنة لاحقًا.
